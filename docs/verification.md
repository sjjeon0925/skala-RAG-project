# 검증 기록

검증일: 2026-09-22. 실제 제공된 PDF 7편, 116쪽을 사용했다.

## 코드·실행 검증

- 단위·회귀 테스트 29개 통과. Python 문법 검사 및 `git diff --check` 통과. 마지막 LPDDR5X 정규식 보정 후에는 사용자 요청에 따라 테스트 묶음을 재실행하지 않고, 진행 중이던 실제 State의 보고서 저장 단계만 완료했다.
- 원본 7편과 프로젝트 PDF의 SHA-256 일치 확인.
- State 16필드, 재검색 최대 2회, 해결된 부족 항목 제거, 네 관점 Fan-in 검증.
- 직접 채택과 생태계 자료 구분, RRF 중복 제거, 기술/역할 필터, 표 parent와 페이지·겹침 보존 검증.
- 인용 ID·수치·단위·실험 조건·반대 근거 누락 검사 및 서지 연도/ID 숫자 오탐 회귀 검사.
- OpenAI/Tavily 실제 연결 테스트 통과.
- 실제 전체 실행: 기술 근거 19개, 관점별 결과 TRL 6 / 시장 3 / 이해관계자 3 / 도메인 10개, 반대 근거 검색 22건.
- 첫 전체 실행은 Report의 숫자 검사에서 발행연도와 근거 ID를 실험 수치로 오인하여 저장을 차단했다. 두 오탐을 수정하고 동일 실행의 Report 입력 State를 재검증해 저장했다. 전체 유료 검색을 다시 실행하지 않았다.
- 결과: `outputs/verification-report.md` 및 `.json` (Git 제외), 최종 의미 검증 후 실제 인용 출처 10개, 본문 27,017자.
- 이제 CLI는 각 완료 단계의 State를 `outputs/state-<run_id>.json`에도 저장한다.

## 최종 보고서 검증 보완

- 일반 CXL 생태계와 대상 CXL-PIM, 별도 시스템 CENT가 혼동된 문장을 확인하여 별도 의미 검증과 출처 구분을 추가했다.
- 추출·평가·Conflict·Synthesis는 원문이 주장의 대상과 의미를 뒷받침하는지 별도 판정하며, 불확실한 문장을 제외한다. 이 역시 LLM 기반 검사로 완전한 사실성 보장은 아니다.
- 긴 근거 ID는 API 내부에서 충돌 없는 짧은 별칭으로 전달하고 응답에서 원래 ID로 복구한다. 미확인 ID는 사실 근거로 채택하지 않는다.
- 발행연도·인용 ID·LPDDR5X 규격명을 실험 수치와 구분하도록 보정했다.
- 최신 로컬 인덱스 710개 청크의 캐시 재사용과 실제 질의 필터를 확인했다.
- 추가 웹 검색 없이 기존 State를 재검증하는 명령: `uv run python scripts/revalidate_state.py outputs/state-<run_id>.json --output outputs/revalidated-report.md`. 이 명령은 OpenAI API를 사용한다.

## small/base 검색 비교

`data/retrieval_cases.json`의 원리·조건·성능·한계 등을 포함한 10개 사례에 영어/혼합 및 한국어 질의를 각각 작성하여 총 20개를 평가했다. 기대 페이지의 anchor가 실제 PDF 추출 텍스트에 존재하는지 먼저 확인한다.

## 제한 사항

- 확장 비교에서 macOS 네이티브 ML 라이브러리의 다중 스레드 실행이 segmentation fault로 종료되었다. CPU 및 Torch/OMP/BLAS 1 thread로 재실행하여 완료했으며, 안정적인 기본값으로 반영했다. 실패한 시도의 지표는 이 표에 사용하지 않았다.
- 평가 라벨은 완전한 정답 집합이 아니다. 다른 페이지에도 올바른 근거가 있을 수 있고, 동일 표 parent의 여러 child가 상위 5개를 차지할 수 있다.
- 표 감지 및 캡션 검사는 휴리스틱이다. 감지된 표 페이지의 주변 조건은 보존하지만, 그림 속 수치/OCR/페이지를 넘는 표의 의미 연결은 자동 검증하지 못한다. 표가 없는 다단 편집의 읽기 순서도 완전하게 복원하지 않는다.
- 참고문헌 페이지는 현재 제외하지 않는다. 인용 논문 제목이 검색에 영향을 줄 수 있다.
- 자동 검증은 인용 문자열·수치·조건의 일치 여부를 검사한다. 주장과 근거 사이의 완전한 의미적 함의나 시장 의견의 대표성을 보장하는 것은 아니다.
- 최초 실행에서 미확보 항목 18개, 추가 의미 검증 후 최종 22개가 남았다. 없는 정보를 채우거나 부정적인 평가로 바꾸지 않았다.
- 현재 보고서 출력은 Markdown이며 PDF 변환과 반 페이지의 실제 인쇄 레이아웃 검증은 제공하지 않는다.
- 별도 강의 가이드 TRL 표는 제공되지 않아 문구 일치 검증은 남아 있다. 적용한 단계 참고 자료는 [구현 기록](implementation-notes.md)에 명시했다.
